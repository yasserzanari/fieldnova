# FieldNova

FieldNova is a decision-support app concept for exploring climate-resilient crop rotations with NASA Earth observation data and local farm context.

## Project structure

- `app/` — application source and user interface
- `data/` — data contracts, fixtures, and ingestion adapters
- `public/` — static assets
- `scripts/` — development and data utilities
- `docs/` — private working documentation; intentionally excluded from GitHub

## Status

Repository initialized. Product implementation and NASA data integrations have not started.

## Documentation

Project notes are kept in the local `docs/` directory and are excluded from version control by `.gitignore`.
