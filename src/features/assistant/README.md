# Assistant FieldNova

The Assistant route pairs a French chat on the left with a parcel map on the right. The map exposes illustrative stress, NDVI, and rainfall overlays, parcel context, a small soil summary, zoom and recenter controls. Chat suggestions change the visible map layer, and each answer exposes its tool trace and reference links.

## Current prototype behavior

- Chat messages, map layers, parcel selection, zoom, recenter, dismissible guidance, source disclosure, and file attachment previews are interactive.
- Replies use local keyword rules to demonstrate how a parcel-aware assistant could respond. They are not generated by a language model.
- Tool traces are demonstration traces. The app does not call NASA, a weather service, a soil API, or an irrigation system.
- The map image and overlays are illustrative and not georeferenced. Soil values are examples; unavailable measurements are identified as missing.
- Attached files are accepted into the chat UI, but their contents are not parsed.

## Archived chat components

`src/components/ai-chat/` contains the supplied FrontUI archive components used for agent activity, source disclosure, message actions, and the multimodal prompt. Their imports and unused declarations were adjusted only where needed for this Vite + TypeScript project.
